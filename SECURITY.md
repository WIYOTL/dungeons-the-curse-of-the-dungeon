# Politique de sécurité / Security policy

## Versions prises en charge / Supported versions

Les signalements sont acceptés pour la dernière version publiée du jeu. Les corrections de sécurité, si nécessaires, ciblent en priorité cette version.

Reports are accepted for the latest published version of the game. Security fixes, when needed, will prioritize that version.

| Version | Prise en charge / Support |
| --- | --- |
| Dernière version publiée / Latest release | Signalements acceptés / Reports accepted |
| Versions plus anciennes / Older versions | Mettre à jour avant le signalement / Please update before reporting |

## Signaler une vulnérabilité / Report a vulnerability

**N’ouvrez pas d’issue publique pour une vulnérabilité.** Envoyez un courriel à [contact.wiyotl@gmail.com](mailto:contact.wiyotl@gmail.com?subject=Signalement%20de%20securite) avec « Security report » ou « Signalement de sécurité » dans l’objet.

**Do not open a public issue for a vulnerability.** Email [contact.wiyotl@gmail.com](mailto:contact.wiyotl@gmail.com?subject=Security%20report) with “Security report” in the subject.

Dans la mesure du possible, indiquez la version concernée, les étapes de reproduction, l’impact potentiel et une solution temporaire éventuelle. Retirez les mots de passe, jetons et données personnelles des journaux ou captures. Ne tentez pas d’accéder aux données d’autres personnes ni de perturber le service.

When possible, include the affected version, reproduction steps, potential impact, and any workaround. Remove passwords, tokens, and personal data from logs or screenshots. Do not access other people's data or disrupt the service.

Nous examinerons le signalement en privé et conviendrons avec vous des étapes suivantes. Aucun délai fixe de réponse n’est garanti pour le moment.

We will review reports privately and coordinate next steps with you. No fixed response time is currently guaranteed.
